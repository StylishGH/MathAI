# 📐 MathAI: Plataforma Inteligente de Aprendizagem Matemática

> **A IA aprende como você aprende Matemática para ajudar você a aprender melhor.**

O **MathAI** é uma plataforma que combina **Ciência de Dados, Machine Learning e Visão Computacional** para mapear o perfil de raciocínio de estudantes de matemática, identificando estratégias favoritas, padrões de erro e recomendando desafios que expandem o repertório cognitivo.

---

## 🚀 Como Iniciar

### 1. Criar e ativar o ambiente virtual:
```bash
python -m venv .venv
# No Windows:
.venv\Scripts\activate
```

### 2. Instalar dependências:
```bash
pip install -r requirements.txt
```

### 3. Executar o aplicativo:
```bash
streamlit run app.py
```
